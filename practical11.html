Web Designing

HTML is used to create the structure of a webpage.

CSS is used to style and format the webpage.

Box Model

The CSS Box Model consists of:

  1. Content
  2. Padding
  3. Border
  4. Margin

CSS Properties Used

Property Purpose
color Changes text color
background-color Changes background color
padding Space inside the element
border Creates a border around the element
margin Space outside the element
text-align Aligns the text

Class vs ID

Class ID
Written using .class Written using #id
Can be used for multiple elements Normally used for one unique element
