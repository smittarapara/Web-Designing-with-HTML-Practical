Welcome, First Year BCA Students!

Bachelor of Computer Applications (BCA) is an undergraduate program designed for students who are interested in computers, programming, software development and technology.

In the first year, students learn the basic concepts of programming, web development, computer fundamentals and problem solving.

About BCA

BCA helps students develop technical and logical skills required to build a successful career in the field of Information Technology.

What will you learn?

  • Computer Fundamentals
  • Programming Concepts
  • HTML and CSS
  • Database Fundamentals
  • Problem Solving
  • Communication Skills
