Images and Image Maps in HTML

1. Image in HTML

The <img> tag is used to display an image on a webpage.

2. Image Map

An Image Map allows us to make different parts of an image clickable.

Click on a region of the map:

3. Important Tags

Tag Purpose
<img> Displays an image
<map> Creates an image map
<area> Creates a clickable area
usemap Connects the image with the map

4. How It Works?

  1. Use <img> to display the image.
  2. Add usemap="#indiaMap" to the image.
  3. Create <map name="indiaMap">.
  4. Use <area> to create clickable regions.
  5. Click on a region to open its webpage.
