# 📖 About this Repository

This repository contains laboratory practicals, HTML programs, CSS exercises, assignments, mini projects, and learning resources developed for the **Web Designing using HTML (CAE1001C)** course.

The practicals provide hands-on experience in HTML5, CSS3, webpage design, responsive layouts, multimedia integration, navigation menus, forms, website planning, and AI-assisted web development.

---

# 🎯 Course Outcomes

- Explain web design principles, website planning, web standards, and audience requirements.
- Develop structured web pages using HTML elements, multimedia, and forms.
- Apply CSS techniques to create responsive and visually appealing webpage layouts.
- Design basic websites using web publishing concepts and AI-assisted web design tools.

| No. | Practical Title |
|:--:|-----------------|

| 6 | Create a webpage incorporating images and image maps. |
| 7 | Create a webpage using audio and video elements. |
| 8 | Design a Student Registration Form using HTML form controls. |
| 9 | Apply Inline CSS to format a webpage. |
| 10 | Apply Internal and External CSS to create a consistent webpage design. |
| 11 | Implement CSS Classes, IDs, and Box Model properties. |
| 12 | Create a responsive navigation bar and webpage layout using CSS. |
| 13 | Design a personal profile website consisting of multiple linked webpages. |
| 14 | Use AI tools to generate webpage content, color themes, and layout suggestions. |
| 15 | Develop a mini website (4–5 pages) integrating HTML and CSS concepts. |
