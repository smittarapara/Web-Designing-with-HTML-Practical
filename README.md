## 📖 About This Repository

This repository contains all practical experiments, HTML programs, assignments, and mini projects developed for the **Web Designing with HTML** laboratory course.

The objective of this repository is to help students understand the fundamentals of web development by creating structured webpages using HTML5 and basic CSS. Each practical is organized with proper documentation, source code, screenshots, and output for easy reference and learning.

---

## 🎯 Course Objectives

- Learn the fundamentals of HTML5.
- Design structured web pages using HTML elements.
- Apply formatting, hyperlinks, images, tables, and lists.
- Create forms and multimedia webpages.
- Develop simple responsive web pages.
- Build mini web projects using HTML and CSS.
