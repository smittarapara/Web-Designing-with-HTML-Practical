## 📖 About

This repository contains practical experiments, HTML programs, CSS exercises, mini projects, assignments, and learning resources for the **BCA Semester I** course **Web Designing with HTML (CAE1001C)**.

The practicals cover the fundamentals of HTML, CSS, responsive web design, multimedia integration, forms, and AI-assisted web development.

---

## 🎯 Course Outcomes

- Design basic web pages using HTML.
- Create webpages using lists, tables, images, hyperlinks, multimedia, and forms.
- Apply CSS to create responsive and attractive webpages.
- Develop multi-page websites using HTML, CSS, and AI-assisted tools.

---

## 🧪 Practical List

| No. | Practical |
|-----|-----------|
| 1 | Create a basic HTML webpage using headings, paragraphs and text formatting tags. |
| 2 | Design a webpage using ordered, unordered and description lists. |
| 3 | Create a webpage using various HTML text and page formatting elements. |
| 4 | Create a webpage demonstrating internal and external hyperlinks. |
| 5 | Design HTML tables using Rowspan and Colspan. |
| 6 | Create a webpage incorporating images and image maps. |
| 7 | Create a webpage using audio and video elements. |
| 8 | Design a Student Registration Form using HTML form controls. |
| 9 | Apply Inline CSS to format a webpage. |
| 10 | Apply Internal and External CSS to create a consistent webpage design. |
| 11 | Implement CSS Classes, IDs and Box Model properties. |
| 12 | Create a responsive navigation bar and webpage layout using CSS. |
| 13 | Design a personal profile website consisting of multiple linked webpages. |
| 14 | Use AI tools to generate webpage content, color themes and layout suggestions. |
| 15 | Develop a mini website (4–5 pages) integrating HTML and CSS concepts. |
