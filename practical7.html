🎵 Audio and 🎬 Video in HTML

Web Designing Practical

1. Audio Element

The <audio> element is used to add audio/music to a webpage.

Play Audio

2. Audio Attributes

  • controls - Displays play, pause and volume controls.
  • autoplay - Starts the audio automatically.
  • loop - Repeats the audio again and again.
  • muted - Starts the audio without sound.

Audio with Loop

3. Video Element

The <video> element is used to add a video to a webpage.

Play Video

4. Video Attributes

  • controls - Displays video controls.
  • width - Sets the width of the video.
  • height - Sets the height of the video.
  • autoplay - Starts the video automatically.
  • loop - Repeats the video.
  • muted - Starts the video without sound.

5. Audio and Video Together

HTML allows us to add both audio and video elements on the same webpage.



6. Important HTML Tags

Tag / Attribute Purpose
<audio> Adds audio to webpage
<video> Adds video to webpage
<source> Specifies the media file
controls Displays media controls
autoplay Automatically plays media
loop Repeats the media
muted Mutes the media

7. Basic Syntax

Audio

<audio controls>
  <source src="audio.mp3" type="audio/mpeg">
</audio>

Video

<video controls>
  <source src="video.mp4" type="video/mp4">
</video>
